# Control de Costos - PWA

Primera versión gratuita, sin Lovable y sin API de pago.

## Incluye
- Resumen diario de ventas, costos, utilidad y margen.
- Registro rápido tipo "Vega" con frases simples.
- Venta manual.
- Registro de gastos e insumos.
- Registro de mermas.
- Calculadora de costo por producto.
- Datos guardados en el teléfono mediante localStorage.
- Instalable como PWA.
- Compatible con GitHub Pages.

## Publicar gratis en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube estos archivos a la raíz.
3. En Settings > Pages selecciona Deploy from a branch.
4. Elige `main` y carpeta `/root`.
5. Guarda.
6. Abre la URL que GitHub te entregue desde el teléfono.
